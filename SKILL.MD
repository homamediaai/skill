# Scenario Writing Skill

## Purpose
Create professional social media and advertising scenarios.

## When to use
Use this skill when the user requests:
- Instagram reels scripts
- advertising videos
- storytelling content
- product introduction scenarios

## Instructions

When creating a scenario:

1. Identify:
- Target audience
- Brand tone
- Goal of content

2. Structure the scenario:
- Hook (first 3 seconds)
- Problem or need
- Solution/product introduction
- Benefits
- Call to action

3. Provide:
- Scene description
- Camera angle
- Visual direction
- Voice over text
- On-screen text

4. Keep scenarios:
- engaging
- concise
- suitable for social media
- aligned with brand identity
